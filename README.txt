Transformer Lab

Open index.html (the Learning Road) in Chrome, Edge, Firefox or Safari. Everything works offline.

Folder layout
  index.html, tree.html        the two dashboards
  lessons/<domain>/index.html  roadmap for each domain
  lessons/<domain>/<lesson>.html  one page per lesson
  interview/                   Interview Academy (one page per question)
  plan/day-N.html              30-day plan
  pages/                       glossary, directory, flashcards, resources, notes...
  playground/, simulator/      interactive tools
  assets/                      CSS, JavaScript, fonts (shared by all pages)

Dotted-underlined words are glossary terms: hover or tap them for a definition.
Progress, bookmarks and notes are saved in your browser.
